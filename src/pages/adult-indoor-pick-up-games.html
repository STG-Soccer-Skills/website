Frequently asked questions

What skill level is this for?
All skill levels are welcome. Games are competitive but friendly, and teams are balanced so everyone gets good runs.
What do I need to bring?
Soccer shoes (no cleats), shin guards if you wear them, and water. We handle the rest.
How does check-in work?
Simple - show up and we'll check you in. Check-in is fast so games start on time.
What happens if turnout is high?
We limit spots to keep games quality. When needed, we use a second field so everyone keeps playing.
