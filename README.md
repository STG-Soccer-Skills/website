# stgsoccerskills.com

The STG Soccer Skills website. Every change pushed to `main` rebuilds and publishes the site automatically (about 1 minute).

## Where things live
- `src/pages/` — one file per page. The file name is the page address: `src/pages/schedule.html` → stgsoccerskills.com/schedule/
- `src/header.html`, `src/footer.html` — the menu and footer shared by every page
- `assets/` — logo, photos, and `site.css` (colors, fonts, layout)

## Editing a page
Open the file in `src/pages/`, click the pencil icon, make your change, and click **Commit changes**. The first two lines set the page title and the Google description:

```
<!--title: Page title | STG Soccer Skills-->
<!--desc: One-sentence description for Google.-->
```

## Adding a page
Create a new file in `src/pages/` named after the address you want (e.g. `fall-camp.html`), copy the top two lines from another page, and add your content.
